# FF ID Recovery — community guide

A responsive static website built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — images supplied in the ZIP

This is an informational community guide, not an account recovery service. The UID form validates numeric input locally and does not determine ban status. A follow-up view displays the entered UID and explains that this site cannot verify account status because it has no authorized API or account database. No payment is collected. The entered UID stays in the browser and is not sent or saved by this site. Use Garena's official support website for account-specific help, and verify official domains before signing in. Use images only if you have permission to reuse them.
